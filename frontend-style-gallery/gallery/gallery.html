前端视觉风格图库

21 种风格 · 包含像素风、2D 卡通、极繁和文化艺术方向

极简主义 Minimalism

留白、克制的配色、清晰的字体层级，让内容成为主角。

 扁平化 Flat Design

用纯色、简单图标和规整卡片组织信息，减少材质模拟。

 Material Design Material Design 3

以色彩角色、层级、圆角组件和动效构建统一界面。

 Fluent Design Fluent 2

柔和的表面、圆角、细边框与交互反馈，带有桌面软件气质。

 企业数据风 Enterprise Data

稳定网格、密集而有序的信息、表格与图表，优先支持高效操作。

 玻璃拟态 Glassmorphism

半透明面板、背景模糊、浅边框和叠层制造磨砂玻璃感。

 新拟态 Neumorphism / Soft UI

同色表面配合柔和高光与阴影，呈现轻微凸起或凹陷。

 新粗野主义 Neo-brutalism

粗边框、硬阴影、鲜艳色块和夸张字体，表达强烈个性。

 编辑杂志风 Editorial

大标题、衬线字体、图文交错和精心控制的留白，强调阅读节奏。

 像素风 / 复古游戏风 Pixel / Retro

像素块、等宽字、有限色盘和游戏界面元素带来复古趣味。

 赛博霓虹风 Cyber / Neon

深色背景、荧光色、发光元素和科技感线条。

 插画手绘风 Illustrative / Hand-drawn

手绘角色、有机图形和温暖配色营造亲近、轻松的氛围。

 2D 卡通风 2D Cartoon

平面角色、清楚的轮廓线、纯色填充和轻快的互动气氛。

 华丽极繁主义 / 哥特装饰 Ornate Maximalism

以中世纪哥特教堂为灵感：尖拱、玫瑰窗、花饰细线、宝石色与金色层层叠加，强调精致工艺和仪式感。

 中世纪手抄本风 Medieval Manuscript

羊皮纸底色、装饰边框、衬线字与手抄本式插图。这里展示的是欧洲手抄本方向。

 宗教艺术启发 / 彩窗 Sacred Art / Stained Glass

以宁静的留白、光线与彩窗结构表达神圣空间感；示例具体采用基督教哥特彩窗语汇。

 西域 / 敦煌艺术启发 Silk Road / Dunhuang

借鉴敦煌装饰的青绿、赭红、金色及莲花、卷草等纹样，形成壁画与丝路气质。

 伊斯兰艺术启发 / 几何纹样 Islamic Geometric

重复的几何纹样、对称节奏、植物纹与书法传统；示例只采用抽象几何。

 中国现代设计风 Chinese Contemporary

现代网格与中文排版结合克制的中国红、留白和抽象几何。

 后现代风 Postmodern / Memphis-inspired

不对称构图、几何拼贴、鲜明配色和风格混搭，带有戏谑感。

 中国水墨风 Chinese Ink Wash

墨色层次、山水意象、纸色留白和小面积朱印。
