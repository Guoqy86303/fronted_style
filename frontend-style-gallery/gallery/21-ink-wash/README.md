# 中国水墨风 · Chinese Ink Wash

![中国水墨风示例](preview.svg)

## 视觉特征

墨色层次、山水意象、纸色留白和小面积朱印。

## 常见用途

文化、阅读、茶艺、艺术展览。

## 示例配色

`#f4f0e7 · #444d49 · #b7483b`

## 使用时留意

留白与笔墨节奏比贴一张山水背景更关键；避免压低正文对比度。
